## How to run the automated tests of the two projects

```
  一、运行 python-dotenv 项目的测试

   # 第 1 步：进入根目录（如果不在）
   cd C:\Users\wubin\OOR\katas\python-dotenv
   
   # 第 2 步：激活虚拟环境
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install pytest pytest-cov click ipython
   pip install -e .
   
   # 第 3 步：运行测试（pytest 读取 pyproject.toml，自动找 tests/ 目录）
   pytest tests/ -v

  -------------------------------------------------------------------------------------------------------------------------------

  二、运行 env-check 项目的测试

   # 第 1 步：进入 env-check 子目录
   cd C:\Users\wubin\OOR\katas\python-dotenv\env-check
   
   # 第 2 步：激活根目录的虚拟环境（env-check 使用同一个 .venv）
   ..\.venv\Scripts\Activate.ps1
   
   # 第 3 步：运行测试（pytest 读取 pytest.ini，自动找 test/ 目录）
   pytest -v

```
